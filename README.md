# 新媒学园 · 网络与新媒体专业学习站

为零基础起步的网新专业学生做的四年成长站：路线图、课业速通、AI 批改教练、文案训练场、资源库、作品集。纯前端、零依赖、双击即用，支持手机/电脑双端与 PWA 安装。

## 怎么打开

- **电脑**：双击 `index.html`（960px 以上自动切换为左侧导航 + 多列宽屏布局）
- **手机当 APP 用**：把网站部署到线上（见下文），手机浏览器打开 → 「添加到主屏幕」，即得全屏图标 APP（PWA，支持离线打开已缓存页面）

## AI 批改教练

在「今日」页最下方配置你自己的 AI Key（存本机浏览器 localStorage，不进代码、不随网站部署泄露）：

| 服务商 | 费用 | 获取 |
|---|---|---|
| 智谱 GLM-4-Flash（推荐） | 免费 | bigmodel.cn → 控制台 → API Keys |
| 硅基流动 Qwen2.5-7B | 免费 | siliconflow.cn → API 密钥 |
| DeepSeek | 低价 | platform.deepseek.com |

配置后可用：**标题实验室 AI 点评**（具体性/情绪钩子/传播力三维点评 + 评分 + 改法）、**课业自测 AI 判卷**（对照参考答案指出对漏、给百分制分数和改进建议）。

> 注意：Key 出现在聊天记录或截图中时记得去服务商控制台重置。本机双击打开若遇跨域报错，用 `node serve.js` 之类本地服务器或部署上线后使用（智谱/硅基流动已实测支持浏览器直连）。

## 部署到线上（PWA 生效的前提）

整个网站就是几个文件，丢到 GitHub Pages / Vercel / Netlify 即可上线。部署后：手机「添加到主屏幕」获得 APP 体验（图标 + 全屏 + 离线缓存）；安卓想装 apk 可用 HBuilderX 打包。

## 动效体系

按 Emil Kowalski 的动画规则（github.com/emilkowalski/skills）实现：只动 transform/opacity、入场统一 ease-out 强曲线（cubic-bezier(0.23,1,0.32,1)）、UI 动画全部 <300ms、列表错峰入场（30-80ms）、按钮按压 120ms 缩放、无 `transition: all`、自带 `prefers-reduced-motion` 减弱支持。改样式后若线上没变化，把 `sw.js` 里的 `CACHE` 版本号 +1（离线缓存按版本刷新）。

## ⚠️ 出问题怎么办（自助三步）

网站自带安全系统：启动失败会自动显示红色应急横幅，运行错误会记入"错误黑匣子"（最近 20 条）。「今日页 → 网站体检」可一键诊断 7 项健康指标。

1. **第一步：强制刷新** —— 电脑 `Ctrl+Shift+R`；手机清一下浏览器缓存或无痕窗口打开。90% 的问题（改了样式没生效、页面显示旧内容）都是离线缓存，刷新即好
2. **第二步：数据恢复** —— 如果学习数据异常，用之前导出的备份文件「导入恢复」。**没导出过？** 那从现在开始每两周导出一次
3. **第三步：找 AI 修** —— 打开「网站体检」，把红叉项和错误信息截图发给任意 AI；改 `js/data.js` 前先复制一份，改坏了换回来就行

**安全模式**：启动横幅上的「安全模式」按钮会清空本机数据重建页面——仅在刷新和恢复都无效时使用，用之前确认你导出过备份。
